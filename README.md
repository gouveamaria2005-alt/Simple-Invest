# Simple Invest

Projeto acadêmico desenvolvido para auxiliar investidores iniciantes na análise e compreensão de informações financeiras por meio de uma plataforma web simples, organizada e acessível.

## Objetivo

Desenvolver uma plataforma digital capaz de apresentar informações financeiras de forma intuitiva, facilitando a interpretação de dados de investimentos e auxiliando usuários na análise de ativos financeiros.

## Funcionalidades

- Cadastro de usuário
- Login de usuário
- Pesquisa de ativos financeiros
- Visualização de informações sobre investimentos
- Visualização de gráficos de desempenho
- Acompanhamento de variações dos ativos

## Requisitos Funcionais

### RF001 - Cadastro do Usuário

O sistema deve permitir que o usuário realize seu cadastro na plataforma, informando dados básicos como nome, e-mail e senha.

### RF002 - Login de Usuário

O sistema deve permitir que usuários cadastrados realizem login utilizando e-mail e senha.

### RF003 - Pesquisa de Ativos Financeiros

O sistema deve permitir que o usuário pesquise ativos financeiros para visualizar informações relacionadas aos investimentos disponíveis na plataforma.

## Requisitos Não Funcionais

### RNF001 - Usabilidade da Interface

O sistema deve apresentar uma interface simples, intuitiva e organizada, permitindo que usuários iniciantes consigam navegar facilmente e compreender as informações exibidas.

### RNF002 - Desempenho do Sistema

O sistema deve carregar páginas e informações de investimentos de forma rápida, garantindo uma boa experiência ao usuário.

## Regras de Negócio

### RN001 - Cadastro único por e-mail

O sistema deve permitir apenas um cadastro por endereço de e-mail.

### RN002 - Acesso restrito a funcionalidades

Somente usuários autenticados podem acessar pesquisa de ativos, visualização de informações e gráficos de desempenho.

### RN003 - Dados financeiros apenas para visualização

O sistema possui caráter educacional e não permite compra, venda ou execução de operações financeiras.

## Casos de Uso

### UC001 - Cadastrar Usuário

Permite que um novo usuário crie uma conta no sistema.

### UC002 - Login do Usuário

Permite que o usuário acesse sua conta na plataforma.

### UC003 - Pesquisa de Ativos Financeiros

Permite pesquisar ativos financeiros e visualizar suas informações.

## Protótipo da Aplicação

O protótipo apresenta telas como:

- Página inicial
- Tela de cadastro
- Tela de login
- Dashboard
- Pesquisa de ativos
- Favoritos
- Perfil do usuário

## Conclusão

O Simple Invest busca tornar a análise de investimentos mais acessível, integrando dados em tempo real, notícias relevantes, sistema educativo e interface intuitiva.
